# 🏪 Aplikasi Inventory Hijabela Collection

> Aplikasi inventory untuk membantu UMKM Hijabela Collection
> dalam mengelola persediaan barang.

## ✨ Fitur Utama 

- Login
- Dashboard
- Data Produk
- Data Supplier
- Barang Masuk
- Barang Keluar/Penjualan
- Laporan Stok
- Riwayat Barang
- Profil
- Logout
